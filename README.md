# Track-day rental site: concept

A homepage concept for a track-day motorcycle rental business in Thailand. It's a static HTML/CSS page with an English / Thai / Chinese switcher; add `?lang=th` or `?lang=zh` to the URL to open it in Thai or Chinese.

**Live:** https://mjrobbins18.github.io/track-rental-concept/

The brand, prices and copy are placeholders. This is a design concept for a proposal, not a real business.
